# CopyPasteLibrary - 复制粘贴库

一个强大的剪贴板历史管理工具，帮助您高效管理复制粘贴操作。
  
## 功能特性

### 核心功能
- 📋 **剪贴板实时监听**：自动记录所有复制内容
- 📜 **历史记录管理**：最多保存100条记录，自动去重
- 🖱️ **一键粘贴**：双击历史记录快速粘贴到当前位置
- 📋 **单条复制**：点击复制按钮快速复制内容
- 🗑️ **单条删除**：点击删除按钮移除不需要的记录
- 🔄 **清空历史**：一键清空所有历史记录

### 用户体验优化
- 🎯 **窗口大小记忆**：自动保存和恢复窗口大小
- 🌐 **多语言支持**：支持中文和英文切换
- 📌 **系统托盘**：后台运行，随时通过托盘图标控制
- 📍 **智能定位**：避免屏幕边缘遮挡，下方显示时自动上移
- 🎨 **暗灰色主题**：现代化的暗灰色界面设计
- 📐 **自适应宽度**：词条长度随窗口大小自动调整
- 🔝 **窗口置顶**：始终显示在最上层，不被遮挡
- ⌨️ **全局快捷键**：Ctrl+Space快速显示/隐藏窗口

## 技术栈

- **编程语言**：Python 3.x
- **GUI框架**：tkinter
- **剪贴板操作**：pyperclip
- **快捷键监听**：keyboard
- **键盘模拟**：pynput
- **系统托盘**：pystray + PIL
- **数据持久化**：JSON文件

## 安装说明

### 1. 安装依赖库

```bash
pip install -r requirements.txt
```

### 2. 运行程序

#### Windows
双击 `启动复制粘贴库.bat` 或 `start.bat` 文件

#### 命令行
```bash
python main.py
```

或者使用 `pythonw` 后台运行：
```bash
pythonw main.py
```

## 使用方法

### 基本操作
1. **启动程序**：双击启动脚本或使用命令行启动
2. **复制内容**：正常使用Ctrl+C复制任意内容
3. **显示窗口**：按下Ctrl+Space显示历史记录窗口
4. **粘贴内容**：双击任意历史记录或点击"复制"按钮后粘贴
5. **删除记录**：点击"删除"按钮移除不需要的记录
6. **清空历史**：点击"清空历史"按钮清空所有记录
7. **隐藏窗口**：再次按下Ctrl+Space隐藏窗口

### 系统托盘菜单
右键点击系统托盘图标，可以：
- **显示**：显示主窗口
- **清空历史**：清空所有历史记录
- **语言**：切换显示语言（中文/英文）
- **退出**：完全退出程序

## 配置说明

### 配置文件
程序会在运行目录生成两个配置文件：
- `history.json`：保存历史记录
- `config.json`：保存窗口大小和语言设置

### 语言切换
1. 右键点击系统托盘图标
2. 选择"语言"菜单
3. 选择"中文"或"English"
4. 语言设置会自动保存

## 快捷键说明

| 快捷键 | 功能 |
|--------|------|
| Ctrl+Space | 显示/隐藏主窗口 |
| 鼠标滚轮 | 在窗口中滚动浏览历史记录 |

## 注意事项

1. **后台运行**：程序启动后会在后台运行，通过Ctrl+Space唤醒
2. **数据保存**：历史记录和配置会自动保存到JSON文件
3. **权限要求**：需要管理员权限才能正确监听全局快捷键
4. **系统兼容性**：适用于Windows操作系统
